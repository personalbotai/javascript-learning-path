# Variabel dan Tipe Data

**ID**: `variabel-dan-tipe-data`
**Duration**: 20 menit

## Materi

### Deklarasi
```javascript
const nama = "Archon";   // Konstan
let umur = 25;           // Bisa berubah
```

### Tipe Primitif
```javascript
typeof "Halo"   // "string"
typeof 42       // "number"
typeof null     // "object" (bug!)
```

### Perbandingan
```javascript
5 === "5" // false (strict)
5 == "5"  // true (hindari!)
```

## Rangkuman
- const = tetap, let = berubah
- Selalu gunakan ===

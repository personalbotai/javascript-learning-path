# Perulangan: Loop

**ID**: `perulangan`
**Duration**: 20 menit

## Materi

### For Loop
```javascript
for (let i = 0; i < 5; i++) { console.log(i); }
```

### For...of
```javascript
for (const item of buah) { console.log(item); }
```

### While
```javascript
let i = 0;
while (i < 3) { console.log(i++); }
```

## Rangkuman
- for = kontrol penuh
- for...of = iterasi nilai

# Operator dan Ekspresi

**ID**: `operator-dan-ekspresi`
**Duration**: 15 menit

## Materi

### Aritmatika
```javascript
10 + 3   // 13
10 % 3   // 1
10 ** 3  // 1000
```

### Perbandingan
```javascript
5 === "5" // false (strict)
5 == "5"  // true (coercion)
```

### Nullish
```javascript
null ?? "default" // "default"
```

## Rangkuman
- Selalu gunakan ===
- ?? untuk nullish coalescing

# Pengenalan dan Sejarah JavaScript

**Kategori**: Dasar · **Durasi**: 15-20 Menit

## 🎯 Ringkasan
JavaScript diciptakan pada Mei 1995 oleh Brendan Eich saat bekerja di Netscape Communications. Awalnya bernama Mocha, lalu LiveScript, dan akhirnya JavaScript untuk memanfaatkan popularitas Java saat itu.

---

## 📖 Pembahasan Mendalam

### Lahirnya Bahasa Web
Brendan Eich mendesain prototipe awal JavaScript hanya dalam 10 hari. Tujuannya adalah bahasa skrip ringan untuk browser Netscape Navigator 2.0.

### Standarisasi ECMAScript
Pada 1997, Netscape menyerahkan spesifikasi JS ke ECMA International untuk standarisasi, menghasilkan standar resmi ECMAScript (ES).

### Era Modern: ES6 (ECMAScript 2015)
Rilis ES6 merevolusi JavaScript secara masif dengan menambahkan class, arrow functions, template literals, let/const, promises, dan modules.

## 💡 Tips & Best Practices
- JavaScript adalah bahasa multi-paradigma: mendukung Object-Oriented, Functional, dan Event-Driven programming.
- Selalu gunakan strict equality (`===`) bukan loose equality (`==`).
- Biasakan membaca pesan error secara teliti dari stack trace DevTools.

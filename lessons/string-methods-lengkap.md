# String Methods

**ID**: `string-methods-lengkap`
**Duration**: 20 menit

## Materi

### Dasar
```javascript
str.length;         // 13
str.slice(0, 5);    // "Hello"
str.split(", ");    // ["Hello", "World"]
str.replace("A", "B");
```

### Template Literals
```javascript
const nama = "Archon";
console.log(`Halo, ${nama}!`);
```

## Rangkuman
- String immutable
- Template literals untuk interpolation
